# Getting started

The present repository contains separate Python branches in the MHT-X-particles and MHT-X-bubbles directories. The root repository includes a historical README and setup_mhtenv_pip_first_v2_no_build scripts; these are not yet a modern, cross-platform packaging guarantee.

For a fully self-contained **review without installing Python**, open the [interactive archive](archive/index.html) or download the [updated portable ZIP](archive/downloads/MHTX_Synthetic_Visual_Archive_Portable_2026-11-15_v2.zip). Extract the complete ZIP and open index.html locally; its additional controls are in controls/index.html.

The frozen 2022 PIV-assisted particle reproduction used precomputed per-detection velocity inputs. Full upstream PIV-to-DFI regeneration has not yet been demonstrated.

After modernization this page will gain version-verified installation, supported Python versions, input schemas, example commands and reproducible setup procedures. These future capabilities must not be mistaken for current released support.
